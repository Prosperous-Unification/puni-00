# Authority fixtures

Fixtures that pin the admission authority's on-disk identity across its move from Twilight
Burokrat to Twilight Dash. Each was produced once from source commit
`e57278139bc168eb454125cd2c730d6ed7769f86`. That commit is the S0 split of WBS 080.19, the last
whose Burokrat package held `admission-runtime/authority-store.ts`. None is regenerated by tests.
The dumps are not named `.sql`: every tracked `.sql` file is a migration, and migration lint
refuses one outside a migration tree.

| File                                   | What it is                                                                                    | Read by                                                          |
| -------------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `module-wiki-authority.v5.sqlite-dump` | `sqlite3 .schema` of a store the pre-relocation code created, plus a fresh meta row           | `schema-golden.test.ts`                                          |
| `burokrat-written-v5.sqlite-dump`      | `sqlite3 .dump` of a store the pre-relocation code wrote (one published integration and more) | `schema-golden.test.ts`                                          |
| `burokrat-written-v5.state.json`       | that store's `inspect()` output                                                               | `schema-golden.test.ts`                                          |
| `pre-relocation-burokrat.tar`          | the pre-relocation authority source, for the rollback proof                                   | `integration-races.test.ts` (rollback and archive-refusal cases) |

`pre-relocation-burokrat.tar` has SHA-256
`502f07f713804adf7914beb552f31f76e36870570fb0b7cb5167d42b886504aa`. The test refuses any other
digest and any missing archive. It is the exact output of:

```sh
B=apps/twilight-structure/twilight-burokrat/cli/src
git archive --format=tar e57278139bc168eb454125cd2c730d6ed7769f86 -- \
  $B/admission-judge/authority-identities.ts $B/admission-judge/integration-candidate.ts \
  $B/admission-judge/packet-codec.ts $B/admission-runtime/authority-store.ts \
  $B/admission-runtime/claims.ts $B/admission-runtime/generations.ts \
  $B/contracts/decode-record.ts $B/contracts/records.ts $B/evidence/content-manifest.ts \
  $B/inventory/classify-entries.ts $B/inventory/read-candidate.ts \
  libs/shared/domain/validation/src/core.ts libs/shared/domain/validation/src/errors.ts \
  libs/shared/domain/validation/src/index.ts > pre-relocation-burokrat.tar
```

The paths are the relative import closure of the three old runtime modules, plus
`@shared/validation` at the same commit. Only `arktype` and Bun's built-ins resolve from the
workspace. The archive is vendored so the proof needs no repository history: a squash, rebase or
garbage collection of the source commit cannot break it. The dump-production steps are in
[the change's verify record](../../../../../../openspec/changes/dash-authority-relocation/verify.md).
