# App fonts

`Geist-variable.ttf` and `InterTight-variable.ttf` are redistributable variable fonts under the SIL Open Font License 1.1. Their required notices are `Geist-OFL.txt` and `InterTight-OFL.txt` beside the font files. They came from PUNI's separately licensed font set, not the Novaform theme assets.

Upstream font records: [Geist](https://github.com/google/fonts/tree/main/ofl/geist) and [Inter Tight](https://github.com/google/fonts/tree/main/ofl/intertight). The font families were checked with `fc-scan` before use.

These exact checked-in files accompany the license notices above. The hashes identify the documented assets; inventory classification does not enforce their digests.
