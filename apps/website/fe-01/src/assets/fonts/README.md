# App fonts

`Geist-variable.ttf` and `InterTight-variable.ttf` are redistributable variable fonts under the SIL Open Font License 1.1. Their required notices are `Geist-OFL.txt` and `InterTight-OFL.txt` beside the font files. They came from PUNI's separately licensed font set, not the Novaform theme assets, and the font families were checked with `fc-scan` before use.

They are the same bytes as the design-system copies: upstream records, sizes and SHA-256 digests are in [the core fonts README](../../../../../../libs/shared/adapters/ui-core-01/src/fonts/README.md), and its `brand.test.ts` pins these files to those digests. Inventory classification does not enforce them.
