## Execution

| Assumption                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Took effect in   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| Executors are Codex on the sol model at medium effort, one at a time, each in its own local clone, sandboxed to that clone and a per-attempt temporary root, started from an allowlisted environment with no tokens or agent sockets. Network access is off for every attempt except 020.1, which must reach the package registry to install the owner's own three packages. The sandbox cannot limit which hosts are reachable and lets a process read the whole machine, so that one attempt is accepted as a known exposure, not a contained one. | Execution        |
| Executors cannot commit, because the sandbox makes the clone's Git directory read-only. The planner commits after reviewing each diff and rerunning the verification.                                                                                                                                                                                                                                                                                                                                                                                | Execution        |
| The planning documents are committed once, locally, as the baseline every clone is cut from. That commit holds only the planner's own documents: the batch directory, four corrected design and plan documents, the findings catalogue entry and two document-check exemptions.                                                                                                                                                                                                                                                                      | Execution        |
| Packet 060.1 is held. Its desk research stands; its hands-on experiment returns as a deterministic run in a disposable environment.                                                                                                                                                                                                                                                                                                                                                                                                                  | The batch README |
| Nothing is pushed, published, merged to main or deployed. Results collect on a local integration branch.                                                                                                                                                                                                                                                                                                                                                                                                                                             | Execution        |
| The host gate cannot run on this machine. Every task is reported with the host gate not run.                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Execution        |
| The three work items that need Dany, the node registrations, the Twilight Dash facade and Twilight Navigator stay untouched.                                                                                                                                                                                                                                                                                                                                                                                                                         | The batch README |
| Nx analytics stays as configured. `nx.json` sets `"analytics": true` and Nx offers no environment override, so every Nx command may contact Nx's analytics host, and during the one network-on attempt (020.1) it can. Editing a root configuration file inside an attempt was judged the larger risk. Whether analytics should stay on is an open question for Dany.                                                                                                                                                                                | Execution        |
| Review rounds are capped at three per packet. A third review that says "dispatch after fixes" is answered by the planner applying the named fixes by hand, without a fourth review; a packet still refused after three rounds is held or cut down, not argued with.                                                                                                                                                                                                                                                                                  | Execution        |
| Packet 020.8's slices C (four use cases) and D (nine backend files) were dispatched as one attempt with both checkpoints reported in full, because together they are thirteen files and the planner reviews every entry either way. The two larger groups, E1 and E2, stay separate.                                                                                                                                                                                                                                                                 | Execution        |
| When an attempt stops on a packet defect, the planner fixes the packet on the integration branch, merges that branch into the attempt's clone if work there is already committed, and redispatches. The stopped clone or tree is kept aside, never deleted.                                                                                                                                                                                                                                                                                          | Execution        |
