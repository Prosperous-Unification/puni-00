# Website walkthrough

The reviewed visitor journey, one row per scenario, each mapped to the capture or test that shows
it. It replaces the 2026-09 [prototype](prototypes/README.md), whose twelve-turn, signed-in
sequence predates [ADR 0039](../adr/0039-anonymous-paid-chat-bound-to-the-browser-claim.md).

Evidence prefixes name the file that declares the case:
`screens.mjs` is a capture state in `apps/website/fe-01/browser/screens.mjs`,
`conversation.mjs` a numbered case in `apps/website/fe-01/browser/conversation.mjs`,
`conversation.test.ts` a test in `apps/website/be-01/src/conversation/conversation.test.ts`, and
`conversation-harness.test.tsx` a test in `apps/website/fe-01/src/conversation-harness.test.tsx`.
`apps/website/fe-01/src/walkthrough.test.ts` fails when a named case no longer exists.

| Scenario              | What the visitor sees                                                                                                                        | Evidence                                                                                                                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Home request, AI off  | The Home request opens the manual brief, which offers no Build link; one email sends it to a person.                                         | `screens.mjs:manual`, `screens.mjs:manual-receipt`                                                                                                                                                                                              |
| Home request, AI live | Build shows the Home request read-only in the composer and waits for Send; the manual brief links back to Build.                             | `screens.mjs:build-live`, `screens.mjs:manual-ai`, `conversation.mjs:1`                                                                                                                                                                         |
| Early conversion      | Once the third reply stores a brief, the proposal card is offered at any later turn; a brief saved earlier is kept; submitting hands it off. | `conversation.mjs:1`, `conversation.test.ts:a brief the visitor saved before the third reply is kept`, `conversation.test.ts:a proposal submission hands the conversation off and closes the stream`                                            |
| Eighth-turn cap       | After the eighth visitor turn the limit line replaces the composer and the pre-filled card still submits.                                    | `conversation.mjs:5`, `conversation.test.ts:stages follow the turns, the third reply becomes the brief and the ninth turn is refused`, `conversation-harness.test.tsx:the allowance line uses the server's turn limit`                          |
| AI disabled           | Build shows the disabled row and the Shape your brief link, with no composer.                                                                | `screens.mjs:build-disabled`, `conversation.test.ts:a disabled or unconfigured provider is reported and admits no operation`                                                                                                                    |
| AI paused             | Build shows the paused row, the manual path and the proposal card, with no composer.                                                         | `screens.mjs:build-paused`, `conversation-harness.test.tsx:the paused harness shows the paused row, the manual path and the card, no composer`, `conversation.test.ts:a pause opened by another connection is seen on the next read and stream` |
| Bot check refused     | A tampered or failed browser check shows the manual path instead of a reply.                                                                 | `conversation.mjs:7`, `conversation-harness.test.tsx:a refused check from the API shows the manual path`                                                                                                                                        |
| Lost or missing claim | Without the draft claim the manual brief asks the visitor to start with their request; a foreign claim creates and calls nothing.            | `screens.mjs:manual-nocookie`, `conversation.test.ts:foreign claims, origins and a missing CSRF header create nothing and call nothing`                                                                                                         |
| Cancelled sign-in     | Removed with ADR 0039: there is no prospect sign-in, so Build asserts no sign-in control at five widths.                                     | `screens.mjs:build-live`, `screens.mjs:build-disabled`, `screens.mjs:build-paused`                                                                                                                                                              |
| Operator inbox        | The operator signs in, reads requests, sees the guardrails with an inline pause confirmation and the 30-day funnel.                          | `screens.mjs:operator`, `screens.mjs:operator-inbox`, `screens.mjs:operator-guardrails`, `screens.mjs:operator-funnel`                                                                                                                          |

The operator captures run only when `PUNI_OPERATOR_PASSWORD` is set. Fixture stacks and commands
are in [the polish verification](../../openspec/changes/polish-build-app-screens/verify.md) and
[the harness verification](../../openspec/changes/build-ai-chat-harness/verify.md).
