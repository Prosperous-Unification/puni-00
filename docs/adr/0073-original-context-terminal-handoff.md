# Complete initial handoff through original terminal authority

Initial activation must restore ingress and retire its pending owner without reconstructing live permission from durable evidence or weakening ordinary owner checks. We propose one private original-context continuation and a dedicated terminal phase that disables ordinary effects, retains narrowly typed whole read-only observations, archives exact barriers without replacement and returns through the original lock interval; unknown settlement keeps that interval held. This trades a more explicit terminal API for preserving both monotone recovery and honest post-unlink custody, while independently selected compatible controller implementations remain a prerequisite before exposure.

## Considered options

Allowing ordinary owner assertions to accept a missing pending file would spread terminal authority into unrelated effect APIs. Reopening a completed graph as an owner would confuse evidence with permission. Publishing exposure-complete before the real ingress effect would simplify a reader cycle by recording an untrue result. All three are rejected; this proposed private decision grants no main adoption, host execution or deployment authority.
