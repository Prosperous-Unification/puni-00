## Per-worker memory across assignments

Parked by the user on 2026-09-07. Excluded from the current scope; no
implementation is planned.

across assignments. The hypothesis is that this continuity might improve the user
experience or increase user retention.

This deferral concerns individual worker memory. Searchable session history and
renameable recurring worker identities remain in the agreed direction.
