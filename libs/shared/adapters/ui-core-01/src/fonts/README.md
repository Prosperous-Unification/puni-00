# Core fonts

`Geist-variable.ttf` and `InterTight-variable.ttf` are redistributable variable fonts under the SIL Open Font License 1.1. Their required notices are `Geist-OFL.txt` and `InterTight-OFL.txt` beside the font files. They are the same files `apps/website/fe-01/src/assets/fonts` carries; the website keeps its copies until it adopts a kit, and `brand.test.ts` pins both sets to the digests below.

Upstream font records: [Geist](https://github.com/google/fonts/tree/main/ofl/geist) and [Inter Tight](https://github.com/google/fonts/tree/main/ofl/intertight).
