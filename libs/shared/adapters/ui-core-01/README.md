# shared/ui-core-01

`@ui/core-01`: the one package every UI kit builds on. It holds the token
vocabulary, the brand constants and the `cn` helper, and no component.
`runtime:browser`, `product:shared`, so any product may import it.

What it is and how kits use it: [DESIGN.md](DESIGN.md). Terms:
[CONTEXT.md](CONTEXT.md). The change that introduced it:
`openspec/changes/design-system-foundation`.
