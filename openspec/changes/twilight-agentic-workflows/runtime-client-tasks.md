# Correlated runtime receiver client implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan with independent task and whole-packet review.

**Goal:** Preserve each actual receiver response body with its own validated shared-client reply for the durable authority/claim sender.

**Architecture:** A small injected-transport wrapper creates one capture closure and shared client per call. It preserves the exact Response bytes and delegates all HTTP request/response/refusal schemas to existing contracts. Semantic acceptance and credentials remain outside this unit.

**Tech Stack:** Bun, TypeScript, Fetch Response, current @wbs/contracts; no dependencies or stored-format changes.

**Spec:** [Runtime dispatch design section1](runtime-dispatch-design.md), [intent](runtime-dispatch-intent.md), and the parent WBS bridge delta.
