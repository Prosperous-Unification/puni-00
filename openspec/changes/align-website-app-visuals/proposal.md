# Align the website app with PUNI

## Why

The continuation app still uses a green palette and different typography from the PUNI site. A visitor who submits a request moves into an interface that looks unrelated to the site.

## Outcome

Give the manual brief, studio and operator views the site's neutral white and dark spectral palette, warm gold controls, Inter Tight headings, Geist body text and clean PUNI wordmark. Keep each view readable on desktop and mobile.

## Non-goals

Do not change request, account, chat, concept, operator or API behavior. Do not import licensed Novaform theme code or assets into the public repository.

## Constraints

Keep the existing React structure except the wordmark markup needed for the correct brand treatment. Self-host only fonts licensed for redistribution, retain their license texts, and keep focus and disabled states visible.
