# Ordered implementation roadmap

These are future TDD slices. This planning turn implements none of them. WBS item `060` owns the website subtree; `060.3`/`060.4` are public-site work, `110` is dev deploy, and `080.12` is intake/chat. The WBS project is the mutable schedule and status source; this file records acceptance contracts only. Proposed pilot allowances require operator provisioning before paid calls.

## 0. Public/private repository foundation (WF27 → WF28 → WF29/WF30)

- [ ] 0.1 Bootstrap the verified-empty private `puni-pr-00` from a pinned versioned governance/toolchain baseline, preserving its independent Git history, credentials and release authorization; establish `apps/`, `libs/`, OpenSpec, AGENTS and wiki conventions — test: `private clean clone runs Nx test lint typecheck build`; negative: `missing baseline component blocks bootstrap` with a pinned input removed.

- [ ] 0.3 Prove bidirectional transfer of an eligible project and its explicit local dependency closure at unchanged `apps/` and `libs/` paths, with no absolute checkout assumptions; run the same Nx test/lint/typecheck/build commands in clean-copy fixtures — test: `portable fixture copies public to private and eligible private to public`; negative: `omitted dependency or path collision fails before destination writes` with each fault injected.
