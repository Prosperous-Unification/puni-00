Nx normalizes some invalid raw containers before graph construction, so graph validation alone cannot establish valid configuration.

The repair validates consumed root, raw discovered project/package and retained plugin-graph fields using projections of the installed Nx 23.2.1 schemas and the already declared Ajv 8.20.0 dependency. It preserves optional absent fields, JSONC project files, filtered target-default arrays and package-only workspace projects. Unrelated non-workspace manifests remain outside Nx's consumed configuration. No dependency or lockfile changes are required.
