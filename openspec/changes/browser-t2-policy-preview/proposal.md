## Why

Browser T2 diagnostics expose complete citation verdicts but cannot show how proposed observe, enforce or ratchet choices would treat them. Registering T2 now would change every external rule policy while authenticated Browser evidence and admission remain unresolved. WBS080.39 needs a reviewable mode preview with a bounded claim.

## What Changes

Specify a separate `inspect-browser-t2-policy` diagnostic over the real Browser T2 consumer and a closed external proposed citation policy. Bind the proposal to one exact observation, preserve every case and nested debt, and show citation effects with explicit preview exit semantics. This PR contains design artifacts only; all implementation tasks remain open.

## Non-Goals

No global T2 registration, RulePolicy migration, trusted activation, authentication, execution guarantee, admission, coverage, tested-module inference, structural ledger, source reconciliation or WBS080.39 closure. No production code or global scenario allocation changes in this design packet.
