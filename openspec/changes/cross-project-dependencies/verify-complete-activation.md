## Explicit source-bundled import exception

The activation bundle includes exact SQLite and receipt leaf modules from source libraries that
have no separate Nx build target. Exact-file, anchored-specifier ESLint exceptions intentionally
bypass Nx product/buildable checks for those named edges only. They do not make the dependencies
Nx-buildable. Every other import keeps the complete unchanged options and constraints, including
`enforceBuildableLibDependency: true`; the broad tools allowance remains exactly its original two
entries. Real static graph dependencies and dependency-sensitive inputs remain visible. Receipt
records permit a type-only contracts import and reject a runtime import.
