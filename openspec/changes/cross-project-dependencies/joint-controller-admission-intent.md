# Joint ordinary controller admission and explicit reader transition

## Problem

Ordinary controllers currently rely on owner markers alone. Missing markers can hide active/restoring policy, and new installed-reader flags cannot safely become prerequisites before an existing reader can acquire them.

## Outcome

Every enumerated ordinary controller jointly admits policy and both markers under its real existing canonical or inherited edge description before protected effects. Legacy paths admit exact absent policy only with both markers absent; required paths need ordinary policy. Active/restoring and malformed, unreadable, unknown or required-missing state refuse. New owner admission precedes lower lock creation and holder writes, with original observations rechecked before pending publication.

An explicit, independently selected pre-controller transition updates only the fixed reader bundle on an existing ordinary host. The unchanged pinned old fixed Bun and its actual old inherited-policy reader check provide the initial boundary. Staged new reader checks establish capability only. A genuinely fresh target instead follows the existing separately selected first-reader preparation. Operator instructions distinguish these routes before new controllers are adopted.

## Non-goals

No active deploy/sync compatibility, graph publisher, ingress restoration, owner/fence retirement, successor approval, running solver upgrade, service restart, automatic preparation or fallback. This does not complete the whole cross-project dependency goal or execute held proofs.

## Constraints

No policy deletion, lock recreation or holder writes before admission. Keep original edge intervals and child custody, fixed production paths, current solver lifetime-lock topology and all existing assertions. Permit only exclusive private inert staging before the protected boundary. Independently selected implementation/artifact hashes record the attended operation; they do not issue authority. Reconcile all source with settled current21 before any lease. Missing tools block. This draft grants no source, host/native, main/deploy, Reader38 or separate43 execution authority. Full publisher, exposure, archive, terminal, successor and qualification obligations remain open.
