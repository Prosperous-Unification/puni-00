# First parent STOP context

The current custody diagnostic retains its first failure only in memory and prints the same generic message for every STOP. Helper logs are saved only after exit and both pipe pumps join, so an incomplete attempt provides no reliable parent failure site.

Publish one bounded snapshot of the first parent STOP site and existing original-record states through the already captured stderr descriptor. Preserve the exact cause privately without reading its properties. The snapshot reports presence and recorded state only; it cannot establish hidden helper progress, child exit or pump settlement.

Preserve permanent HOLD, original resources, keeper and deadline, all current caps, oracle and terminal pre-helper reporting. A full, short, thrown or unsupported diagnostic write never authorizes retirement. No new descriptor, timer, observer, retry, signal, process inspection or native attempt is included. Existing held epochs remain immutable. Implementation uses an actual old-source assertion failure and finite inert source-backed controls before any newly reviewed native proposal.
