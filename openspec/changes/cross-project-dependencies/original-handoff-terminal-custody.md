## Original unwind and HOLD

The full owner wrapper captures success/failure but, while still inside ALL original lock callbacks, transitions to closing and awaits scope.closeOriginal(). Only real exit + both original EOF + required stdin/socket/session/descendant closure permits success/settled refusal to propagate and owners.delete/descriptor release. A refused operation never becomes success when its late child settles. If a real late child/pipe finishes with all remote closure proved, the wrapper finally returns the original sanitized failure and releases; no rerun.

A permanent read failure, unavailable original exit or unproved remote cleanup remains HOLD. Keep the original operation promise, private references and existing edge/lower descriptors alive with a referenced passive event-loop keeper; it performs no new probes/retries/effects or deadline renewal. The caller may report sanitized HOLD without claiming the operation returned or locks released. Process death/transport loss is not success or proven descendant extinction; retained durable fences remain.
