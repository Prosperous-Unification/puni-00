## Local observation boundary

The CLI accepts one exact absolute directory beneath /sys/fs/cgroup and uses /proc in the same Linux namespace. A library roots parameter supports offline filesystem fixtures. Realpath containment rejects foreign directories and directory symlink escapes. Exact cgroup.procs membership is compared with each process cgroup-v2 path. Descendant cgroups are not enumerated; memory counters can include descendants and are never equated with summed RSS.

Each sample records its UTC timestamp, monotonic elapsed time and cgroup device/inode identity. Each read opens without following symlinks and with nonblocking flags, requires a regular file, and reads at most 64KiB plus one overflow byte. At most 256 PIDs are accepted. Every process is read twice around command/status inspection to refuse PID reuse or membership changes. Executable readlink targets are compared in full internally, including when their basenames match; only the basename is returned. Known launcher paths yield a role hint; raw command arguments and environment never enter reports or failure text. Unknown launchers remain explicitly unknown.

A monotonic deadline bounds the observation promise and pauses; a CLI watchdog exits the local process on expiry. This is a local event-loop deadline with scheduler tolerance, not a claim about kernel uninterruptible IO or remote sampler termination. There is no remote launcher. Output is one JSON line per complete sample so prior observations survive a later refusal. Exit zero means only that requested observations completed.
