The requests app intercepts the explicit fragment at startup and during same-document navigation. It uses the existing credentialed operator session route to obtain the CSRF token. A browser confirmation prevents the fragment from authorizing a reset on its own. The operator command uses the configured origin boundary and returns only cookie updates. After success the app discards scoped browser storage and navigates to the configured public site.

SQLite reuses the existing preview allowance baseline. A restart registers a new browser claim, fences any live operation for the current draft and writes that baseline in one transaction. It invalidates the old draft claim and preserves its browser binding and conversation accounting. The browser receives the new browser claim and expires its draft and replay cookies. Provider cancellation follows the durable fence. The original preview command retains its resume semantics.
